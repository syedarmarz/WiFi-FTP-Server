# Security policy

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report it privately through **GitHub Security Advisories**: open the **Security** tab of this repository and choose **Report a vulnerability**. Include the steps to reproduce and the Android version.

You will get a reply as soon as possible. Fixes are released in a new version and credited if you like.

## Supported versions

Only the latest release receives fixes.

## Things to know

- Plain FTP is not encrypted. Turn on **Use FTPS** in Settings, or use the app only on networks you trust.
- The password is created randomly on first launch. Change it in Settings if you prefer your own.
- Clients can only see the folder you choose as the root folder.
