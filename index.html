WiFi FTP Server

Move files between your Android phone and other devices, wirelessly and with ease.

Download APK More about the app

Features

Share files over Wi-Fi with FTP or FTPS. Use password access, choose which folder to share, and enable read-only mode when needed.

Security

FTP does not encrypt file transfers. Use FTPS for an encrypted connection, connect only on trusted networks, and stop the server when finished.

Troubleshooting

Keep both devices on the same Wi-Fi and check the server address and login details. Make sure file access is allowed. If the server stops, allow unrestricted battery use.

Privacy

No account is required, and the app has no ads, analytics or tracking. Your files are shared only with devices that connect to your server.
